# IT-Trade · прайс-лист Dahua

Панель для просмотра прайса, умного поиска и сравнения оборудования Dahua.
Next.js 16 (App Router, Cache Components) · FastAPI (async) · SQLAlchemy 2 (async) · PostgreSQL 17 · nginx.

## Запуск

```bash
# .env уже создан со случайными паролями; для нового сервера: cp .env.example .env и заполнить
docker compose up -d --build
```

Всё поднимается само: БД → миграции (Alembic) → создание первого администратора → импорт прайса
из `./seed/*.xlsx`, если каталог пуст → API → фронтенд → nginx.

- Сайт: `http://<host>:${HTTP_PORT}` (по умолчанию порт 80)
- Админка: `/admin` — логин/пароль из `ADMIN_USERNAME` / `ADMIN_PASSWORD` в `.env`
- API-документация: `/api/docs`

## Что где настраивается

| Где | Что |
|-----|-----|
| `.env` | только секреты и деплой: пароли БД, `JWT_SECRET`, первый админ, порт, `COOKIE_SECURE` (true за HTTPS), TTL токенов |
| Админка → Настройки | бренд, акцентный цвет, контакты, показ цен, наценка/скидка %, округление, размер страницы, лимит сравнения, синонимы поиска, правила разбора Excel (листы для пропуска, названия колонок, метки «Новинка»/EOL) |
| Админка → Категории | переименование, порядок, скрытие (переживает повторные импорты) |
| Админка → Товары | фото (URL), скрытие товара |
| Админка → Фото | автоподбор фото с сайта Dahua, проверка близких совпадений, список «не найдено» |

## Импорт Excel

Админка → «Импорт прайса». Кнопка «Проверить без сохранения» показывает, что изменится
(новые модели, рост/снижение цен, что пропадёт). Товары обновляются по модели и **никогда не удаляются** —
отсутствующие в новом файле просто скрываются, поэтому привязанные фото сохраняются.
Из описаний автоматически извлекаются характеристики: Мп, матрица, объектив, ИК/LED, WDR, PoE, ИИ, защита и т.д.

## Умный поиск

Понимает свободный текст и показывает, как понял запрос:
`уличная 4мп купольная poe до 15 тыс`, `ptz 25x`, `nvr 16`, `коммутатор 8 портов`, `2.8мм 8мп`, `hfw2449`.
Фрагменты модели без дефисов, исправление раскладки (`рац2449` → `HFW2449`), синонимы (редактируются в админке),
морфология (русский FTS), нечёткий поиск при опечатках, фасеты с количеством.

## Фото

Фото подбираются автоматически с официального сайта **www.dahuasecurity.com**: при первом запуске
и после каждого импорта для новых товаров (в фоне, прогресс в Админка → Фото).

- Модель из прайса приводится к виду сайта: без префикса `DH-/DHI-`, объектива (`-0280B`),
  PAL-буквы (`HFW2449TP` → `HFW2449T`) и ревизии (`-S2`). Совпадение принимается только точное.
  Если совпало лишь без «мягкого» суффикса (`-PRO`, `(L)`), фото ставится с пометкой «Проверить».
- Берётся галерея со страницы товара (рендеры на прозрачном фоне), фото конвертируются в WebP и
  хранятся локально в томе `backend_data` (`/data/media`). Варианты с разными объективами делят одни файлы.
- Фото, заданные вручную (Админка → Товары), автоподбор никогда не перезаписывает.
- Сайт, пауза между запросами, число фото, размер — в Админка → Настройки → Фото.

Массовая привязка своих фото по модели:

```http
POST /api/admin/products/photos
Authorization: Bearer <access_token>

[{"model": "DH-IPC-HFW2449SP-S-IL-0280B-S2", "images": ["https://.../1.jpg", "https://.../2.jpg"]}]
```

## Авторизация

JWT: access-токен (15 мин) хранится только в памяти браузера, refresh-токен (30 дней) — в httpOnly-cookie
на `/api/auth`, ротируется при каждом обновлении; повторное использование старого refresh отзывает всю сессию.

## Разработка без Docker

```bash
./dev.sh          # Postgres (свой кластер в .dev/) + API с autoreload :8000 + Next.js dev :3000
./dev.sh test     # тесты backend
./dev.sh reset    # стереть локальную базу (прайс заново импортируется из seed/)
```

Нужны python3, node/npm и бинарники PostgreSQL (`sudo pacman -S postgresql`; службу запускать не нужно).
Либо своя база: `DATABASE_URL=postgresql+asyncpg://user:pass@host:5432/db ./dev.sh`.
Порты меняются через `BACKEND_PORT`, `FRONTEND_PORT`, `PGPORT`.
